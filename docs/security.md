# 安全边界

**v0.1 不是可直接公网部署的管理面板。**

- 后端强制监听 `127.0.0.1`；没有认证和 CSRF 防护，不能经 Nginx、Cloudflare 或端口转发直接公开。
- 当前只实现只读 Action；没有任意 Shell、文件修改、终端、特权执行组件或远程 MCP。
- 运行 Web API 的 Linux 账号不应为 root。将来需要管理员权限的功能必须经过专用权限中介，不能靠前端按钮做权限判断。
- 不要将 `.env`、密码、密钥、数据库备份、私人照片或其他业务秘密提交到 GitHub，私有仓库也不能替代密钥管理。
- 操作计划与审核确认需要绑定；真实命令和参数应经后端检查；审计日志需要防篡改、脱敏与合理的保存策略。
- 在线导入第三方模块意味着以面板进程身份运行第三方 JavaScript，Manifest 不能提供安全沙箱。该能力暂不实现。
- 公开 Web/MCP 前，至少需要登录、授权、CSRF/Origin 校验、限流、超时、审计、审批、回滚与恢复演练。
