# 里程碑

1. **v0.1（已完成）**：模块注册、基础 Fastify / Vue、只读 Action。
2. **v0.2（本 PR）**：Output Schema、结果验证、可插拔 Renderer、系统/内存/CPU/磁盘监控、结构化服务列表、自动化测试。
3. **v0.3（后续）**：身份认证、权限、审计、只读 API 访问安全、不可变计划及审批机制。
4. **v0.4（后续）**：授权后的 MCP 适配器，复用 Registry 和 Engine。
5. **v0.5（后续）**：可审查的系统服务管理、隔离的特权操作组件。
6. **后续**：文件/终端/Nginx/PHP/数据库/备份模块，逐步取代宝塔。

每个里程碑：需求说明 → 原理与数据口径 → 实现 → 测试 → 代码审查 → 故障和恢复检查。所有高风险操作必须在安全模型成熟之后开放。
